# External Resources Policy

This public mirror does not vendor external datasets, lexicons, local models, or
reference repositories.

External resources may be used locally for:

- salience and complexity features;
- Chinese and English lexical resources;
- relation schema candidates;
- graph construction research;
- optional embedding retrieval.

Users are responsible for downloading resources under their original licenses.
When a resource is required for an experiment, keep it outside the repository,
for example under `external_references/`, which is ignored by default.
