
## 已知边界

- mock smoke 只证明链路，不证明模型抽取质量。
- hash embedding 只用于 integration smoke，不证明语义检索质量。
- `mock_regex_baseline` 只保留为 baseline/test path，不是 v0.3 主 fidelity path。
- current view 是可重建投影，不是 durable truth。
- graph current 是审核后的图候选当前视图，不是 graph truth。
- graph metrics、community reports、visualization 都不是 evidence proof。
- S3 / support checker authority 不在本轮范围内。

## 发布判断

可以把 v0.41 称为：

```text
v0.41 usable-alpha workflow integration accepted on mock/synthetic path plus bounded live provider smoke.
```

不应称为：

```text
production-ready
quality-proven live provider system
durable memory writing system
graph truth system
```

下一步建议：

1. public mirror 本地同步已完成；push GitHub 仍需单独显式授权。
2. 决定私有 `.env` 的默认模型策略：保留按环境覆盖，或改为当前 provider 可用模型。
3. 给 `workflow_runner build-full` 增加显式 provider/model override 参数，减少临时环境变量覆盖。
